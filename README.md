Journey Buddy

> PLAN SMART • EXPLORE BETTER • TRAVEL SAFELY • GET HELP FASTER

JourneyBuddy is an AI-powered, safety-integrated tourism platform designed to support travellers throughout the complete journey — Discover, Plan, Reach, Experience, Stay Safe, Adapt, Return and Review.

**Core Innovation - Hybrid SOS System**
One-tap SOS, GPS location, SMS fallback without internet, Trusted Circle alerts, cached emergency info.

**Features**
Phoenix AI, Core Travel Modules, Ticket Wallet, Trip Readiness, Trip Budget, Community Hazard Pins, Crowd Pulse, Smart Plan-B.

**Tech Stack**
React + Vite, Tailwind CSS, Phoenix AI, Supabase, Google Maps API, Vercel.

```bash
npm install
npm run dev
